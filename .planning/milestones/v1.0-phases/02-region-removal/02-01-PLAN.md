<objective>
Build the coordinate-mapping spine: a pure, isolated module that converts a rectangle expressed in browser-image pixels (at the known render DPI) into a PyMuPDF `Rect` on the **unrotated** page, and back. This is the highest-risk component of the whole tool (research PITFALLS 1–2, ARCHITECTURE Pattern 2 / Build-Order step 3) — an off-by-rotation or off-by-DPI mapping silently redacts the wrong area. It MUST be proven by a round-trip test harness at 0/90/180/270° and an offset-MediaBox page **before** any redaction code (Plan 02-02) depends on it.

Purpose: One tested place that gets px↔pt, DPI scale, rotation (`derotation_matrix`), and non-(0,0) MediaBox right, so every downstream edit path is correct by construction (REMOVE-03 — "所見即所得", correct even on rotated pages).
Output: `app/services/coords.py` (pure module) + `tests/test_coords.py` (round-trip + placement proof at all four rotations + offset MediaBox).
</objective>
