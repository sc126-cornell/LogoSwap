## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Repo visibility flip 預設不可逆 | AGPL §13 要求 public,但「private → public」會一次性公開所有 git history;不應在沒有使用者明確同意下用 `gh repo edit --visibility public` | advisory | 部署前明確 surface 此選項給使用者三選一(public / Artifex 商業授權 / 內網限制);本 session 已按此 pattern 執行 |
| Dockerfile runtime bug 單元測試抓不到 | `pip install --target /install` 把 package executables 放 `/install/bin/`,但 python:3.12-slim 預設 PATH 不含;`uvicorn app.main:app` 啟動直接噴 "not found"。pytest 全綠也無法揭露 | advisory | 任何 Dockerfile 改動必須以「實機 docker build + docker run + 觸發 entrypoint」驗收,不能只看 pytest;Pitfall 已在 `Dockerfile` 加 WHY 註解 + memory `project_deployment_licensing.md` 收錄 |
