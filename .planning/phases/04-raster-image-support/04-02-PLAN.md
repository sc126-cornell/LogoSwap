       ```python
           UNROTATED-page space (same space as ``rect``), so no derotation matrix is
           needed here.

           are fitz APIs — the AGPL seam invariant requires every fitz access route
           through this module (threat T-02-03). ``redact.py`` and ``pipeline.py`` stay
           fitz-free.

           [VERIFIED: Phase 4 RESEARCH Pattern 4 本機實測 PyMuPDF 1.27.2.3:
              get_image_rects 在 single-image PDF 上回 [Rect(0.0, 197.875, 595.0, 644.125)]
              — letterbox 上下留白與 image 區清楚分離]
           """
           q = fitz.Rect(rect)
           q.normalize()
           for entry in page.get_images():

               for img_rect in page.get_image_rects(xref):

                   # _rects_overlap but kept inline here for a tight type contract:
                   # this helper takes fitz.Rect, _rects_overlap takes tuples).
                   if ir.x0 <= q.x1 and q.x0 <= ir.x1 and ir.y0 <= q.y1 and q.y0 <= ir.y1:
                       return True

       ```

       ```python
                to redact it.

                true-removal guarantee is the IMAGE_PIXELS pixel-blank, NOT the drawing graph.
       ```
