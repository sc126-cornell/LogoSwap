<objective>
Implement the core value: **true removal**. Given a region payload from the browser (rectangles in image-pixel space at the known DPI, per page), open the session's **work copy** (never the original), map each rectangle through the proven coordinate mapper (Plan 02-01), and **truly remove** the text and vector objects inside it via PyMuPDF redaction — not a cover. Save the redacted work copy so it can be re-rendered as the "移除結果" (after) image, and export a full-page PDF named `原名_logoswap.pdf` for download. This is a complete, automatically-testable backend slice (no UI needed to prove it): a region in → content provably gone + a downloadable PDF out, with the original untouched.

Purpose: Deliver REMOVE-01 (truly removed, not covered — extraction returns empty), the server half of REMOVE-04 (the result render that the before/after toggle shows) and OUTPUT-01 (download), with REMOVE-03's correctness inherited from the 02-01 mapper. Deferred-mutation (D-05): redaction happens only here, on the work copy, at process time.
Output: `RegionMark`/`JobSpec` models; `redact.remove_region`; `pipeline.process_job`; `POST /sessions/{id}/process` + result-render + download endpoints; tests proving emptiness, original-immutability, and correct export.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /process | Untrusted JSON (page indices, pixel rects, dpi, region count) crosses into the redaction pipeline. This is the primary new attack surface of Phase 2. |
| pipeline → work copy / original | The pipeline must mutate ONLY the work copy; the original (chmod 0o444) is the integrity boundary that must never be crossed. |
| outputs file → GET /result | A generated PDF is streamed back; the served path must be confined to the session's outputs dir. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / DoS | Out-of-bounds / malformed / inverted `px_rect` in the JobSpec | mitigate | Validate `px_rect` length + numeric via Pydantic; apply `coords.clamp_px_rect` (Plan 02-01) against the page's img_w/img_h before mapping so a rect can never redact or read outside the page; zero-area after clamp is skipped, never a crash. |
| T-02-04 | Denial of Service | A JobSpec with a huge `regions` list or absurd `dpi` driving unbounded redaction/render cost | mitigate | Cap `len(regions)` via `MAX_REGIONS` (config, default ~200) -> 422 over the cap; `dpi` validated into `[MIN_DPI, MAX_DPI]`; redaction runs in `run_in_threadpool`; reuse the existing render pixel-budget fit (`fit_dpi_to_pixel_budget`) for the after-image. |
| T-02-05 | Tampering (integrity) | Pipeline accidentally mutating the immutable original (violates UPLOAD-04 / D-05) | mitigate | Pipeline opens `storage.work_path` only and asserts the path is not `original_path`; original stays chmod 0o444; an automated test hashes the original before/after a process run and asserts equality. |
| T-02-06 | Information disclosure / path traversal | `session_id` or output filename used to read/stream a file outside the session's outputs dir | mitigate | `session_id` flows through the existing `validate_session_id`/`session_exists` allowlist (crafted id -> 404, no oracle); the download serves a FIXED on-disk output name from `outputs_dir(id)` (the CJK display name is set only in the Content-Disposition header, never used as a path) — reuses the Phase-1 path-traversal guard without regressing it. |
| T-02-07 | Information disclosure | "Covers but does not remove" — supplier text/vector still extractable from the exported PDF | mitigate | Mandatory post-redaction emptiness assertion (`get_text`/`get_drawings` over the unpadded region empty) in `remove_region`; `apply_redactions` always called; `PDF_REDACT_TEXT_NONE` forbidden (grep check). This is the core-value security control (REMOVE-01). |
| T-02-08 | DoS / availability | Malformed PDF or redaction edge case raising an unhandled exception -> 500 leaking internals / killing a worker | mitigate | Reuse the engine's `PdfEngineError` typing; map pipeline/redact failures to structured `{detail:{code,message}}` via a `main.py` handler (mirror Phase 1); redaction wrapped so a parser failure becomes a typed 4xx, never a bare 500. |
</threat_model>
